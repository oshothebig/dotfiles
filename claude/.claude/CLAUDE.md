## コーディング規約

- 特別の指示が無い限り、ソースコード中のコメントは英語で記述します
- 特別の指示がない限り、 YAML ファイルを作成する時の拡張子は `.yaml` を使用します
- Markdown ファイル
    - インデントは 4 スペースを使う
    - リストは特別の指示がない限り `-` を使う
    - 指示がない限りリスト項目の先頭の語句をボールドにしない (例: `- 項目: 説明` とし `- **項目**: 説明` としない)
- 囲み数字 (①②③) は使わず、代わりに `1)`, `2)`, `3)` などを使う

## Git

- 指示がない限りコミットログは英語で書く

## ツール利用

- 作業ディレクトリ外のリポジトリを操作する場合のみ `git -C {repo} {subcommand}` を使い、それ以外は `git {subcommand}` を使う
