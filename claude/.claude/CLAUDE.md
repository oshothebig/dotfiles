## コーディング規約

特別な指示がない限り以下のルールに従う

- ソースコード中のコメントは英語で記述する
- YAML ファイル
    - 拡張子は `.yaml` を使用する
    - リストはインデントしない
- Markdown ファイル
    - インデントは 4 スペースを使う
    - リストは `-` を使う
    - リスト項目の先頭の語句をボールドにしない (例: `- 項目: 説明` とし `- **項目**: 説明` としない)
- 囲み数字 (①②③) は使わず、代わりに `1)`, `2)`, `3)` などを使う

## Git

- 指示がない限りコミットログは英語で書く

## ツール利用

- 作業ディレクトリ外のリポジトリを操作する場合のみ `git -C {repo} {subcommand}` を使い、それ以外は `git {subcommand}` を使う
- `Makefile` の代わりに `justfile` を使う。既に `Makefile` を使っている場合は利用を継続する。

## 予定の調整・空き時間の検索

指示がない限り以下の基本原則に従う

- 予定のスケジュール可能時間を探すときは 11:30 - 13:30 を対象から除外する。
